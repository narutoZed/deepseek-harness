# Agent Note: Mesh SDK 上游集成

Status: implemented

[English](2026-09-08-mesh-sdk-upstream-integration.md) | 中文

## Problem

Mesh 依赖本 fork 维护的原生会话分支、持久化恢复、运行中输入、人工回答、助手流式事件、子代理元数据和会话树完成判定。上游版本独立演进持久化 API，未必同步适配这些 SDK 扩展。

## Decision

本 fork 合并上游源码，并保留 SDK 扩展及其公开的能力协商。会话导出通过异步、优先读取实时会话的观察接口选取已完成轮次的前缀；冷读取使用原生版本迁移和存储读取器。导出保留源会话，并将选定前缀导入独立存储。

运行时上下文标题为 `权限：`。文件策略说明使用 `Current file policy`；workspace-write 说明包含解析后的会话工作目录。这些文案调整保留策略解析、审批执行、快照来源和抑制机制。历史消息保留原文；当前快照发生变化时，通过既有投影追加新快照。

Python SDK 源码与部署的运行时来自同一集成修订。仅凭包版本不能识别本 fork 的扩展。

## Alternatives considered

直接用上游版本替换本 fork 会移除 Mesh 使用的 SDK 操作。新 Python 包搭配旧运行时，会使运行时行为脱离版本保证。保留旧冷导出实现会误读持久化返回值，导致创建分支前失败。

## Consequences

上游修复与本 fork 的 SDK 行为使用同一构建。SDK 测试覆盖冷导出、独立分支续跑、能力协商、原生完成判定、单次审批、后代控制和部署级可写目录。模型可见提示词的预期输出跟随定制文案更新，同时保留历史会话代际。
