# Agent Note: SDK 会话树活动结束

Status: implemented

[English](2026-09-05-sdk-session-tree-settlement.md) | 中文

## Problem

高层 SDK 运行在根 agent 首次空闲时返回，此时后台子 agent 或父 agent 的后续工作可能仍在进行。消费者重复维护运行时生命周期状态，并可能遗漏提供方的异步准备阶段。

## Decision

服务器声明会话树活动结束能力，并在原生根会话与后代等待机制完成后发布新增的结束通知。原生管理器拥有准备阶段与执行生命周期，包括不应阻塞完成的停驻空闲子会话。SDK 活动修订号防止先前的等待结束新接受的活动区间。两个客户端默认等待协商确定的标记，并提供显式首次空闲返回选项；旧运行时保留原行为。没有持久终止记录的原生失败通过 `session.settled.error` 报告，并拒绝客户端运行。

## Alternatives considered

**客户端子 agent 计数器。** 创建不等于已接受的工作，传输消费者无法可靠重建提供方准备阶段或原生运行周期。

**空闲后延迟。** 宽限时间无法证明工作已完成。

## Consequences

升级配套的运行时和客户端后，消费者可以删除会话树运行包装器。原始驱动器状态和逐提示词入队语义保持不变。原生活动结束不保证资源释放，也不会合成父 agent 输出。确定性测试覆盖并发准入、独立根会话、失败报告、inbox 唤醒和等待观察器关闭后的静止状态；受门控的真实 SDK 进程覆盖后台子 agent 完成后的父 agent 汇总。
