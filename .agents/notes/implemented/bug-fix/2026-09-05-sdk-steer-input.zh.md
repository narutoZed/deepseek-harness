# Agent Note: SDK 下一步输入

Status: implemented

[English](2026-09-05-sdk-steer-input.md) | 中文

## Problem

SDK 宿主无法通过下一轮提示词引导正在运行的 agent。缺少调用方身份也让宿主无法把待处理输入与持久用户消息对应起来。

## Decision

`session/steer` 通过核心 agent 的下一步操作准入带身份的输入。它拒绝不存在或空闲的会话，并在进程内复用已成功或正在处理的相同请求。相同 id 搭配不同内容会拒绝；准入失败不保留重试回执。两个 SDK 客户端均提供这一操作。提示词提交可以把调用方身份保留为 `source.rpcId`。

## Alternatives considered

**所有更新都排队。** 这会把引导推迟到下一轮，与宿主要求的操作不符。

**承诺持久重试恢复。** 进程内回执映射无法做出这一保证；持久请求身份只支持关联。

## Consequences

宿主无需重新实现核心收件箱即可进行中途引导。单元和真实 profile 测试保持模型请求等待，准入引导，并验证下一次请求只消费一次。运行时二进制与客户端需要配套升级；进程重启后的回执恢复仍是独立工作。
