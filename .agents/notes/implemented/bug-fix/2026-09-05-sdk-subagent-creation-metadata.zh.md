# Agent Note: SDK 子代理创建元数据

Status: implemented

[English](2026-09-05-sdk-subagent-creation-metadata.md) | 中文

## Problem

子代理描述符可能在实时会话事件转发开始前，已经在准备阶段或恢复历史中建立。因此 SDK 宿主只能收到子级 id，拿不到 Web 目录能读取的标签和模式，只能关联工具调用或解析工具展示文本。

## Decision

SDK 创建通知通过原生描述符读取器投影可选的标签、模式和提供方字段。首个兼容的子级自身描述符仍是权威来源；继承的祖先描述符不参与识别。元数据不受支持或损坏不会阻断谱系通知；私有组合字段不对外复制。

## Alternatives considered

**解析工具回执文本。** 展示文本不是稳定的元数据 API；工具并行完成也会让按位置关联出错。

**重放全部构造事件。** 这会改变事件流语义，并暴露超出创建标签需要的状态。

## Consequences

宿主可以删除新 SDK 会话的标签重建逻辑，同时保留自己的旧日志迁移。普通子会话及不兼容的持久描述符仍可以省略字段。种子会话测试和真实前台和后台子代理验证创建标签、模式以及私有字段排除。
